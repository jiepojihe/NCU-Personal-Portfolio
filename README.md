## 📚 课程简介

本仓库用于存放本学期 **16 周** 课程实验/作业/学习笔记。  
采用「一周一文件夹」的目录结构，每个文件夹内按需放置：

- `README.md` —— 本周实验说明、实验目的、实验要求
- `code/` 或 `src/` —— 源代码
- `report.md` 或 `docs/` —— 实验报告
- `assets/` —— 截图、流程图等附件

## 🛠️ 使用说明

1. 每周完成实验后，把代码/报告放入对应的 `weeks/weekXX/` 文件夹。
2. 修改完成后，在本仓库目录下执行：
   ```bash
   git add .
   git commit -m "weekXX: 完成 XXX 实验"
   git push
   ```
3. 推荐使用 **VS Code** 作为编辑器，仓库已忽略 `.vscode/` 个人配置。
